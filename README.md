# SmartPantry
Planejador de refeições, lista de compras e despensa. Front-end em HTML/JS puro, dados no navegador (localStorage).
[Demo](https://github.com/J3f3r/smartpantry/)

## Como foi desenvolvido
Projeto de aprendizado feito com apoio do Claude (IA) para gerar e corrigir o código.
Meu papel: definir os requisitos, revisar o comportamento, planejar e executar testes
(casos de teste e sessões exploratórias em /docs) e escrever testes unitários (/test).

## Limitações
Sem backend, sem login, sem sincronização entre dispositivos e sem backup. Preços são estimativas.

## Rodar os testes
npm install && npm test
